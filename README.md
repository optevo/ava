# AVA: AI Value Assessment (preview)

AVA is a browser-based tool for building and discussing a business case: it compares one way of delivering software (for example OutSystems) with an alternative (for example AI coding plus cloud-native), in terms of time to production, cost and business value.

**Open it:** https://optevo.github.io/ava/

It is a single static web page. There is nothing to install and no server: it runs entirely in your browser.

## Your data

Everything you type stays in your browser. It is kept in your browser's local storage on this site (so it is there when you come back) and is never sent to a server. The only thing collected is anonymous usage statistics for this public site (Google Analytics: page visits, with the visitor's approximate location and device type); nothing you type into the app is included, and it is switched off if your browser sends a Do Not Track signal. Files you export (Excel, PowerPoint) contain what you entered, so handle them like any other business document. Clearing your browser's site data removes the saved copy. Because this site shares its address with other GitHub Pages sites under the same account, avoid entering anything confidential on a shared or public computer.

## What it can do

- Compare two approaches over a chosen period: delivery time, cost and value, with scenarios and a "how sure are we" view.
- Build the value of each application from simple figures or calculators, and group applications into delivery teams that can start on different dates.
- Export the assessment to Excel (readable sheets with formulas) and import it again, and export a PowerPoint (plain, unbranded).
- Work in English, German, French, Spanish, Italian, Portuguese (European and Brazilian), Japanese, Korean, Traditional Chinese, Thai, Indonesian and Vietnamese. Translations are machine-assisted and not all reviewed.
